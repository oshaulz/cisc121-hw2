# Queen's Student Page

My CISC 121 student webpage, hosted with GitHub Pages.

**Live site:** https://oshaulz.github.io/cisc121-hw2/

## Files

- `index.html` — page content
- `style.css` — Queen's colours and styling
- `me.jpg` — profile photo

## Running locally

Open `index.html` in a browser. Any commit to `main` redeploys the live site.
